description: Verify work before claiming completion — evidence before assertions
---

Invoke the Skill tool to load the "superpowers-verification-before-completion" skill. Follow the Gate Function:

1. **IDENTIFY** — What command proves this claim?
2. **RUN** — Execute the FULL command (fresh, complete)
3. **READ** — Full output, check exit code, count failures
4. **VERIFY** — Does output confirm the claim?
5. **THEN CLAIM** — State result WITH evidence

Iron Law: NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE. Never use "should", "probably", or "seems to" — run the command and read the output first.
