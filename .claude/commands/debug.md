Invoke the Skill tool to load the "superpowers-systematic-debugging" skill. Follow the Four Phases rigorously:

1. **Root Cause Investigation** — Read errors, reproduce, check recent changes, gather evidence. NO FIXES WITHOUT ROOT CAUSE FIRST.
2. **Pattern Analysis** — Find working examples, compare against references, identify differences.
3. **Hypothesis and Testing** — Form single hypothesis, test minimally, verify before continuing.
4. **Implementation** — Create failing test case first, implement single fix, verify.

Iron Law: NO FIXES WITHOUT ROOT CAUSE INVESTIGATION FIRST.
