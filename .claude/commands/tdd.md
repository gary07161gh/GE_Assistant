Invoke the Skill tool to load the "superpowers-test-driven-development" skill. Follow the Red-Green-Refactor cycle:

1. **RED** — Write one minimal failing test showing what should happen
2. **Verify RED** — Watch it fail (MANDATORY — confirm test fails for correct reason)
3. **GREEN** — Write minimal code to pass the test
4. **Verify GREEN** — Watch it pass (MANDATORY — confirm all tests pass)
5. **REFACTOR** — Clean up, keep tests green

Iron Law: NO PRODUCTION CODE WITHOUT A FAILING TEST FIRST. If you wrote code before the test, delete it and start over. No exceptions.
